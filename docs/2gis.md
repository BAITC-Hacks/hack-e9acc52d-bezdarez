# Карта 2ГИС

В `frontend/.env.local` задайте `VITE_DGIS_API_KEY` с доступом к Map Tiles API / MapGL JS API и перезапустите Vite. Для production переменную нужно задать перед сборкой. Пример — `frontend/.env.example`; `.env.local` исключён из Git. Браузерный ключ виден посетителю сайта по устройству SDK; ограничения доменов и квоты настраиваются в кабинете 2ГИС.

SDK загружается по требованию из официального CDN `https://mapgl.2gis.com/api/js/v1`, без новых npm-зависимостей. После загрузки карта показывает Астану, цветные районы и модельные показатели из существующего расчёта. Слои, выбор района и результаты симуляции обновляют тот же районный слой. Кнопка «Все районы» возвращает общий вид, на телефоне перемещение выполняется двумя пальцами.

Режим «Схема» сохраняет прежнюю автономную SVG-карту. Она также включается автоматически при отсутствии ключа, ошибке SDK, недоступности WebGL, ошибке карты или превышении времени ожидания загрузки. Кнопка «2ГИС» позволяет повторить попытку.

Контуры взяты из существующего упрощённого снимка `astanaMap.ts`, а не из административных данных 2ГИС. Геопривязка восстановлена по контрольным координатам OSM relations 3486954, 20593940 и 3479876. Округление SVG даёт погрешность порядка десятков метров; границы не предназначены для адресных или юридических решений. Сохраняются пять районов модели приложения, без подмены актуальными административными границами. Показатели и влияние проектов остаются демонстрационными.

Документация: [подключение SDK](https://docs.2gis.com/en/mapgl/start/first-steps), [Map, Polygon и HtmlMarker](https://docs.2gis.com/en/mapgl/reference/class), [параметры и события](https://docs.2gis.com/en/mapgl/reference/interface).
